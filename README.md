# TaskFlow

A simple task management app built using Next.js, Redux Toolkit, and RTK Query.

## Features

- Add Tasks
- Delete Tasks
- Toggle Completed Tasks
- Search Tasks
- Filter Tasks
- API Integration using RTK Query

## Tech Stack

- React
- Next.js
- Redux Toolkit
- RTK Query
- Tailwind CSS
- TypeScript

## Run Locally

```bash
npm install
npm run dev
